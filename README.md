# Neural Tycoon

Империя нейросетей в неоновом техно-нуаре. После дуополии флагманов (GPT-6 Astra, Claude Opus 5.5) доступ к моделям стал товаром. Серые шлюзы перепродают урезанные сети, даунгрейдят и подменяют ответы. Вы — оператор-архитектор чистого шлюза, строите сеть от перцептрона до сингулярности. Оригинальный стек без костылей.

## Механики

**Экономика и прогрессия:**
- 5 типов зданий: Токенизация (BPE), Матрицы Attention, Вероятностный инференс, Флагман GPT-6 Astra, Model Verifier
- Система апгрейдов для каждого типа здания
- Контракты с клиентами (принять → выполнить → получить награду)
- Менеджеры для автоматизации покупки зданий
- 8 квестов с наградами
- Система престижа: сброс прогресса в обмен на GWARP-ключи и ранг
- Дерево технологий за науку (7 узлов с зависимостями)

**Угрозы и события:**
- Серые шлюзы атакуют каждые 45 секунд (55% шанс)
- Model Verifier блокирует атаки (ZERO SPOOFING)
- Без Verifier: -50% дохода на 20 секунд

**Визуал:**
- Изометрическая карта с кубом-ядром в центре
- Здания размещаются "звездой" вокруг ядра
- Анимированные линии-связи с пульсами
- Частицы дохода летят от зданий к ядру
- Тултипы с информацией о зданиях

**PWA:**
- Устанавливается как приложение на мобильные устройства
- Работает оффлайн после первой загрузки
- Service Worker кэширует все ассеты
- Landscape ориентация для мобильных

## Как играть

1. **Старт:** У вас 20 монет. Купите первое здание BPE (15 монет).
2. **Рост:** Здания приносят пассивный доход. Покупайте больше зданий и апгрейды.
3. **Контракты:** После lifetime 1000 появляются контракты. Примите и выполните за награду.
4. **Защита:** Купите Model Verifier для защиты от серых шлюзов.
5. **Автоматизация:** Наймите менеджеров для автопокупки зданий.
6. **Наука:** Исследуйте технологии за науку (получаете от контрактов и квестов).
7. **Престиж:** При lifetime 1M+ сбросьте прогресс для GWARP-ключей (+10% дохода за ключ).

**Управление:**
- Клик по зданиям в магазине — покупка
- Клик по апгрейдам/технологиям — улучшение
- Hover по зданиям на карте — тултип с информацией
- Кнопка "Исследования" — дерево технологий
- Кнопка "Сброс" — новая игра

## Локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build

# Превью production сборки
npm run preview
```

Dev-сервер запустится на `http://localhost:3000`

## Технологии

- **Frontend:** Vanilla HTML/CSS/JS (без фреймворков в runtime)
- **Сборка:** Vite
- **Графика:** Canvas 2D API
- **Звук:** Web Audio API (синтезированные звуки)
- **PWA:** Service Worker, Web App Manifest

## Разработка

**Дебаг-режим** включён по умолчанию:
- Стартовые ресурсы: 1M монет, 1K науки
- Порог престижа: 1K lifetime
- Кнопка "DBG" в правом нижнем углу

Отключить: `?debug=0` в URL или `localStorage.setItem('nt_debug', '0')`
